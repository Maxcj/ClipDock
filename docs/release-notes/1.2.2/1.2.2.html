ClipDock 1.2.2

Release notes for the stable update channel.

本次更新

ClipDock 1.2.2 带来完整的外观主题控制，让主窗口和设置窗口都可以跟随系统、固定浅色或固定深色显示。深色界面也经过重新调校，文字、分隔线、按钮和窗口边缘更柔和，长时间查看剪贴板历史时不再那么刺眼。

  • 新增外观设置，可选择跟随系统、浅色或深色模式
  • 主窗口和设置窗口会同步应用所选外观，不再只依赖系统当前主题
  • 优化深色模式下的主窗口文本、筛选项、详情面板和删除按钮对比度
  • 调整设置窗口深色模式下的侧边栏、内容区域和分隔线，让界面颜色更一致
  • 主窗口深色模式外层背景使用更接近非活动状态的色调，减少活动窗口边缘黑线感
  • 统一项目命名与发布配置中的 ClipDock 标识，后续构建和发布流程更清晰

What’s New

ClipDock 1.2.2 adds complete appearance control across the app, so the main window and Settings can follow the system, stay light, or stay dark. Dark mode has also been tuned with softer text, dividers, buttons, and window edges for a calmer clipboard browsing experience.

  • Added an Appearance setting with System, Light, and Dark options
  • The main window and Settings window now apply the selected appearance together instead of relying only on the current system theme
  • Refined dark-mode contrast for main-window text, filters, the detail panel, and the destructive delete action
  • Improved the Settings window sidebar, content background, and divider treatment in dark mode for a more unified surface
  • Updated the dark-mode outer window background to better match the inactive-window tone and reduce the visible black edge while active
  • Unified ClipDock naming in project and release configuration for clearer future builds and releases
