ClipDock 1.2.0

Release notes for the stable update channel.

本次更新

ClipDock 1.2.0 把这一轮 beta 中打磨完成的性能、预览和安全交互改进正式带给所有用户。大历史量搜索更顺滑，文件副本会在后台保存并显示清晰状态，预览和代码详情更轻量，设置里的高风险操作也更明确。

  • 文件副本改为后台异步保存，并显示 pending / cached / failed / skipped 等状态
  • 搜索增加归一化索引和输入 debounce，在更大的历史记录中响应更稳定
  • 图片详情页避免提前加载原图，预览面板会根据屏幕尺寸自动调整
  • 超长代码内容会自动降级为纯文本显示，减少详情页卡顿
  • “重置系统分类”和“清除所有历史记录”使用更清晰的操作样式与确认流程

What’s New

ClipDock 1.2.0 brings the performance, preview, and safer workflow refinements from this beta cycle to the stable update channel. Large history search feels smoother, file copies now save in the background with visible cache states, preview and code detail views are lighter, and higher-risk settings actions are clearer before they run.

  • File copies now save in the background and report pending / cached / failed / skipped states
  • Search uses normalized indexing plus input debounce, keeping larger histories more responsive
  • The image detail view avoids loading the original image up front, and the preview panel adapts to screen size
  • Very long code content automatically falls back to plain text to reduce stutter in the detail view
  • “Reset System Categories” and “Clear All History” now use clearer action styling and confirmation flow
