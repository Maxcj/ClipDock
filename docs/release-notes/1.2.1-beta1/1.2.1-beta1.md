# ClipDock 1.2.1-beta1

ClipDock 1.2.1-beta1 聚焦剪贴板历史的稳定性和图片预览体验。监控逻辑被拆分为更清晰的服务层，重复复制会把已有内容重新置顶，图片文件预览也更适合处理大文件。

### 本次更新

- 拆分剪贴板监听、捕获、分类、去重、存储、清理和图片处理职责，后续维护更清晰
- 重复复制已有内容时不再新增重复记录，而是更新使用时间并回到列表顶部
- 为内容 hash 和最近使用时间增加数据库索引，让查重和排序更可靠
- 从文件复制图片时使用 ImageIO 生成受限尺寸预览，避免大图片一次性读入内存
- 图片预览第一次点击即可打开，并在屏幕可见区域居中显示

ClipDock 1.2.1-beta1 focuses on clipboard history reliability and a smoother image preview experience. The monitor has been split into clearer services, duplicate copies now promote existing items, and image file previews are safer for large files.

### What’s New

- Split clipboard monitoring, capture, classification, deduplication, storage, cleanup, and image handling into clearer responsibilities
- Recopying existing content no longer creates duplicate records; it updates the usage time and moves the item back to the top
- Added database indexes for content hashes and recent usage times to make deduplication and ordering more reliable
- Image files copied from disk now use ImageIO to create bounded previews instead of loading the whole file into memory
- Image previews open on the first click and stay centered within the visible screen
