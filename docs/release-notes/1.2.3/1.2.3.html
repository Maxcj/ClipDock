ClipDock 1.2.3

Release notes for the stable update channel.

本次更新

ClipDock 1.2.3 继续打磨深色模式体验，让图片详情、预览弹窗、颜色详情和设置中的操作按钮在深色外观下更自然，也顺手移除了已经不再使用的旧版视图与重复数据模型。

  • 优化图片类型详情区域的预览按钮、占位状态和预览表面，使其在深色模式下不再突兀
  • 图片预览弹窗改为无标题栏展示，查看复制项图片时界面更干净
  • 调整颜色详情、文件/链接详情图标和设置页清除按钮的深色模式对比度
  • 移除旧版 Legacy 视图代码，保留当前详情页所需的代码预览能力
  • 删除重复的 ClipDockV1 Core Data model，项目结构更轻、更清晰

What’s New

ClipDock 1.2.3 continues polishing the dark appearance with better treatment for image details, preview windows, color details, and Settings actions. It also removes unused legacy views and the duplicate old data model to keep the project leaner.

  • Refined the image detail preview button, placeholder state, and preview surface for a more natural dark-mode appearance
  • Removed the title bar from the image preview popup for a cleaner copied-image viewing experience
  • Tuned dark-mode contrast for color details, file/link detail icons, and the Settings clear action
  • Removed unused Legacy view code while preserving the current code-preview experience
  • Deleted the duplicate ClipDockV1 Core Data model to simplify the project structure
