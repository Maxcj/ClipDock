# ClipDock 1.2.0-beta1

ClipDock 1.2.0-beta1 brings together the performance and workflow refinements from this beta line. File copies now save in the background with explicit cache states, search is smoother on larger histories, previews use less memory, and the more destructive settings actions are clearer and safer to use.

### 本次更新

- 文件副本改为后台异步保存，并补上 `pending / cached / failed / skipped` 状态
- 搜索增加归一化索引和输入 debounce，大历史量下更顺滑
- 图片详情页不再提前加载原图，预览面板也会自动适配屏幕尺寸
- 代码高亮对超长内容自动降级为纯文本，减少详情页卡顿
- 设置里的“重置系统分类”和“清除所有历史记录”都改成更明确的操作样式

ClipDock 1.2.0-beta1 brings together the performance and workflow refinements from this beta line. File copies now save in the background with explicit cache states, search is smoother on larger histories, previews use less memory, and the more destructive settings actions are clearer and safer to use.

### What’s New

- File copies now save in the background and expose `pending / cached / failed / skipped` states
- Search uses normalized indexing plus input debounce, which stays smoother as history grows
- The image detail view no longer loads the original image up front, and the preview panel now adapts to screen size
- Code highlighting automatically falls back to plain text for very long content, reducing detail-page stutter
- The “Reset System Categories” and “Clear All History” actions now use clearer, safer action styles
